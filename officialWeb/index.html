Designed for Interactive Displays

A dedicated Raspberry Pi 5 kiosk platform for exhibitions, retail, installations and digital signage

📡

PIR Motion Trigger

GPIO-based motion triggering is the default operating mode, designed for reliable and low-overhead interaction.

📷

Optional Camera Mode

Camera/OpenCV motion detection is already integrated in the software and can be enabled without changing the core system.

🎬

Fullscreen Media Playback

HDMI-connected displays can automatically play configured video content in fullscreen when motion is detected.

📱

Remote Admin Panel

Trigger source, video path, audio level, cooldown and detection settings can be managed from a phone, tablet or computer on the same network.

⚙️

Automatic Startup

The system is designed to start automatically with the Raspberry Pi and return to motion monitoring without manual intervention.

🛡️

Private Software

The application source code remains private. This public page presents the product and its capabilities without exposing the implementation.

Technical Specifications

Hardware

  • Board: Raspberry Pi 5
  • Trigger: PIR GPIO sensor
  • Display: HDMI screen / TV / monitor
  • Camera: Optional USB or Pi Camera

Software

  • OS: Raspberry Pi OS
  • Playback: mpv fullscreen
  • Admin: Local web interface
  • Camera mode: OpenCV based

Operation

  • Startup: Automatic service launch
  • Default source: PIR
  • Alternative source: Camera
  • Playback: Configurable media file

Control

  • Trigger: Select PIR or camera
  • Video: Path and volume control
  • Motion: Cooldown and sensitivity
  • Status: System state and logs

System Delivery

modInteractive is delivered as a configured private software solution rather than a public source-code package.

1

Raspberry Pi 5 Platform

The application runs locally on Raspberry Pi 5 and controls motion-triggered fullscreen content playback.

2

PIR by Default

The standard system uses a PIR sensor. Camera hardware is optional; camera detection support remains included in the software.

3

Remote Configuration

Operational settings can be adjusted from the built-in local admin panel without exposing application source code.
