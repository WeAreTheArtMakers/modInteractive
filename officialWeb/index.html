Designed for interactive displays

A private software layer that turns a passive screen into a responsive installation.

A dedicated Raspberry Pi 5 kiosk platform for exhibitions, retail, installations and digital signage.

📡01

PIR Motion Trigger

GPIO-based motion triggering is the default operating mode, designed for reliable and low-overhead interaction.

📷02

Optional Camera Mode

Camera/OpenCV motion detection is already integrated and can be enabled without changing the core system.

🎬03

Fullscreen Media Playback

HDMI-connected displays automatically play configured video content in fullscreen when motion is detected.

📱04

Remote Admin Panel

Trigger source, video path, audio level, cooldown and detection settings can be managed from the same network.

⚙️05

Automatic Startup

The system starts automatically with Raspberry Pi and returns to motion monitoring without manual intervention.

🛡️06

Private Software

The application source code remains private. This public page presents the product and its capabilities without exposing the implementation.

System delivery

Configured as a complete private installation.

modInteractive is delivered as a configured private software solution rather than a public source-code package.

01

Raspberry Pi 5 Platform

The application runs locally on Raspberry Pi 5 and controls motion-triggered fullscreen content playback.

02

PIR by Default

The standard system uses a PIR sensor. Camera hardware is optional; camera detection support remains included in the software.

03

Remote Configuration

Operational settings can be adjusted from the built-in local admin panel without exposing application source code.
